# Politica de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en Eurabyte Security Terminal, por favor **no
abras un issue publico**. En su lugar, reportala de forma privada mediante
[GitHub Security Advisories](https://github.com/josedavidosorio2005/Security-Terminal/security/advisories/new)
en este repositorio.

Incluye, en la medida de lo posible:

- Una descripcion clara del problema y su impacto.
- Pasos para reproducirlo.
- La version de EST y el sistema operativo utilizados.

Nos comprometemos a confirmar la recepcion en un plazo razonable y a mantenerte informado
mientras se investiga y, si corresponde, se corrige.

## Alcance

EST es una herramienta de pentesting pensada para auditar sistemas propios o expresamente
autorizados. El uso de EST contra sistemas sin autorizacion queda fuera del alcance de soporte
de este proyecto y es responsabilidad exclusiva de quien lo ejecuta. Ver
[docs/SEGURIDAD.md](docs/SEGURIDAD.md) para el modelo de autorizacion de la herramienta.
